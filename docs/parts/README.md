# Quy ước tài liệu PART

P01–P13 chưa có báo cáo triển khai. Khi một PART được duyệt và hoàn thành, tạo `docs/parts/PXX-<ten>.md` theo cấu trúc sau:

1. Mục tiêu.
2. Phạm vi.
3. Chức năng đã làm.
4. File thay đổi.
5. API hoặc database liên quan.
6. Quy tắc nghiệp vụ và phân quyền.
7. Cách chạy thử.
8. Test cases.
9. Kết quả test thực tế.
10. Phần còn mock/chưa triển khai.
11. Vấn đề tồn tại.
12. Hướng dẫn bàn giao cho PART tiếp theo.

Không tạo báo cáo giả cho PART chưa thực hiện. Liên kết roadmap tại [MASTER_ROADMAP](../MASTER_ROADMAP.md), bối cảnh tại [PROJECT_CONTEXT](../../PROJECT_CONTEXT.md) và trạng thái sống tại [CURRENT_STATUS](../CURRENT_STATUS.md).
